# 部署说明

## 一、服务器准备（Linux）

1. 安装 Docker 与 Docker Compose
2. 确保服务器能访问数据库 `80.238.234.89:6883` 和飞驼接口 `openapi.freightower.com`

## 二、配置

编辑 `backend/.env`（已含初始值）：
- 数据库密码以 `DB_PASSWORD_B64`（base64）形式存储，避免特殊字符被 dotenv 截断
- 如需修改密码，用命令生成：`echo -n '新密码' | base64`
- `SECRET_KEY` 生产环境务必改成随机长字符串
- `SYNC_INTERVAL_MINUTES=30` 定时同步周期

## 三、数据库变更

在数据库执行一次（新增 voyage 字段）：
```sql
ALTER TABLE transit_containers
ADD COLUMN voyage varchar(50) DEFAULT NULL COMMENT '航次' AFTER ship_name;
```
> 说明：程序已做字段自适应，即使暂不执行也能运行（只是航次不回写）。creator 字段需为字符串类型（当前库已是 varchar(200)）。

## 四、启动

在项目根目录（`ops-management/`）执行：
```bash
docker compose up -d --build
```

访问 `http://服务器IP:8001/`

## 五、常用操作

```bash
docker compose logs -f              # 查看日志
docker compose restart              # 重启
docker compose down                 # 停止
docker compose up -d --build        # 重新构建并启动
```
